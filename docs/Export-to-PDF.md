## How to export this guide to PDF (Windows)

Option 1 — VS Code extension (recommended)
- Install extension: "Markdown PDF" by yzane.
- Open `docs/Cheating-Detection-System-Guide.md`.
- Press Ctrl+Shift+P → "Markdown PDF: Export (pdf)".
- The PDF will be generated alongside the markdown file.

Option 2 — Print to PDF from a Markdown preview
- Open the markdown in VS Code.
- Right-click → "Open Preview".
- Ctrl+P → choose a PDF printer (e.g., "Microsoft Print to PDF").

Option 3 — Browser
- Use a Markdown viewer in the browser or GitHub viewer.
- Print (Ctrl+P) → Save as PDF.

Notes
- Mermaid diagrams: if the exported PDF doesn’t render mermaid, use the Markdown PDF extension (it supports mermaid) or install "Markdown Preview Mermaid Support".
- Page breaks: You can add `\n\n---\n\n` in the markdown to suggest section breaks.
